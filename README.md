# Personal Portfolio

My personal developer portfolio — showcasing projects, skills, and experience as a Full-Stack Software Engineer.

## Live

🔗 [yishak-tule.vercel.app](https://yishak-tule.vercel.app)

## Built With

| Layer | Technology |
|---|---|
| Framework | Next.js 14 (App Router) |
| Styling | Tailwind CSS |
| Language | TypeScript |
| Deployment | Vercel |

## Sections

- **Hero** — intro and call to action
- **Projects** — featured work with live links
- **Skills** — tech stack overview
- **Contact** — links and email

## Getting Started

```bash
git clone https://github.com/isakhu/portfolio
cd portfolio
npm install
npm run dev
```
